# 安心看盘

面向长辈的手机端市场信息助手，提供每日 A 股概览、企业优劣分析、行业观察、同业比较和美股行业参考。

## 数据源

- 正式模式：服务端接入 TuShare Pro，并使用 D1 缓存按交易日更新的数据；美股参考还需单独开通美股日线权限。
- 演示模式：未配置 `TUSHARE_TOKEN` 时自动使用明确标注的演示数据。
- 数据密钥只保存在服务端环境变量中，不会发送到浏览器。
- 美股行业使用 SPY、QQQ、DIA、XLK、XLV、XLY、XLE、XLI、XLF、XLP 作为参考代码；正式上线前必须用实际账户逐项预检覆盖情况，缺失或日期不一致的数据会标为“暂无”，不会伪装成 0。

即使仅供家人访问，也应在接入个人 Token 前取得数据供应商对共享展示、缓存和派生分析的书面授权；未获授权时保持演示模式。
