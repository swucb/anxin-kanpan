# 安心看盘

面向长辈的手机端市场信息页，提供 A 股行情、企业财务、行业公司对比和美股行业参考。

## 数据源

- A 股和美股行情使用 TradingView 官方免费嵌入组件，不需要 API key。A 股为收盘数据，美股为延迟行情，并保留原始署名。
- 宏观数据使用世界银行 Indicators API，由服务端每天检查并缓存；不需要 API key。
- 页面不抓取、转存或二次计算 TradingView 行情，只做官方组件内的展示与对照。
- 不再提供演示行情，也不依赖访客登录。

## GitHub Pages

仓库通过 GitHub Actions 构建静态页面，并在工作日收盘后刷新宏观数据与中美行业对比数据。Pages 版本不需要访客登录。
